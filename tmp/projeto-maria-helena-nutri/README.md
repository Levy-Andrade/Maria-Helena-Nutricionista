# Landing Page - Maria Helena | Nutricionista

Este projeto é uma Landing Page moderna, responsiva e de alta conversão feita especialmente para a nutricionista **Maria Helena (@maria.helena_nutri)**.

## ✨ Recursos
- 100% responsivo (Celular, Tablet e Desktop).
- Sem necessidade de instalar Node.js ou rodar comandos `npm` (HTML5, Tailwind CDN e JS puro).
- Calculadora de hidratação diária interativa.
- Links diretos do WhatsApp configurados para consulta Presencial e Online.
- Accordion de FAQ interativo.

## 🚀 Como testar no seu computador (VS Code)
1. Extraia o conteúdo do arquivo ZIP.
2. Abra a pasta no seu **VS Code**.
3. Clique com o botão direito no arquivo `index.html` e selecione **"Open with Live Server"** (ou apenas dê dois cliques no `index.html` para abrir diretamente no seu navegador).

## 🌐 Como subir no GitHub e publicar na Vercel

### Passo 1: Subir para o GitHub
No terminal do seu VS Code:
```bash
git init
git add .
git commit -m "Landing page Maria Helena Nutricionista"
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
git push -u origin main
```

### Passo 2: Publicar na Vercel
1. Acesse [vercel.com](https://vercel.com) e conecte sua conta do GitHub.
2. Clique em **Add New...** -> **Project**.
3. Selecione o repositório que você acabou de subir.
4. Clique em **Deploy**. A Vercel detecta automaticamente como um site estático e publica seu site em menos de 1 minuto!
